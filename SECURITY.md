# Security Policy

This is a static, fictional demonstration. No live model dispatch, cloud action, authentication, credentials, broker execution or local mutation is available from the UI.

Report suspected vulnerabilities privately through GitHub private vulnerability reporting or security advisories when enabled; otherwise contact the repository owner privately. Do not paste secrets, logs or personal data into public issues.

A security scanner, line-by-line disclosure audit, license review and independent security assessment are mandatory before first publication. Synthetic demo evidence does not establish a production security certification.
