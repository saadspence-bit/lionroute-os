# Security Policy

This is a static, fictional demonstration. No live model dispatch, cloud action, authentication, credentials, broker execution or local mutation is available from the UI.

Report suspected vulnerabilities privately through GitHub private vulnerability reporting or security advisories when enabled; otherwise contact the repository owner privately. Do not paste secrets, logs or personal data into public issues.

Every proposed release or update must pass a dedicated secret scan, disclosure review, dependency/security checks, and review of licensing and network-access boundaries. GitHub Actions is configured for repeatable safety checks; a passing CI run is not a production security certification. Do not publish operational traces, source credentials, private workspace logs, or unapproved live adapters.
